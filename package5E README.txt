
1.Copy spacex.css to css folder.
2.Copy particles.js, parallax.js, stars.js to js folder.
3.Paste spacex-hero.html near top of index.html.
4.Add in head:
<link rel="stylesheet" href="css/spacex.css">

5.Add before </body>:
<script src="js/particles.js"></script>
<script src="js/parallax.js"></script>
<script src="js/stars.js"></script>

No overwrite required.
