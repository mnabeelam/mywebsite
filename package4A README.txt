INTEGRATION WITH EXISTING PACKAGES

1. Copy css/glass.css and css/dashboard.css into existing css folder.

2. Copy js/dashboard.js into existing js folder.

3. Open sections/dashboard.html and paste its contents before Contact section in index.html.

4. Add to <head>:
<link rel="stylesheet" href="css/glass.css">
<link rel="stylesheet" href="css/dashboard.css">

5. Add before </body>:
<script src="js/dashboard.js"></script>
