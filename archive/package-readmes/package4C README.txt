
PACKAGE 4C INTEGRATION

1. Copy css/terminal.css to existing css folder.
2. Copy js/terminal.js to existing js folder.
3. Open sections/terminal.html and paste contents before Contact section.
4. Add in <head>:
<link rel="stylesheet" href="css/terminal.css">

5. Add before </body>:
<script src="js/terminal.js"></script>

No overwrite required.
