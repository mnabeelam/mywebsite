
PACKAGE 11A

1. Copy earth3d.css into css folder.
2. Copy earth-engine.js, stars-engine.js and mouse-controls.js into js folder.
3. Add earth3d.html near top of body.
4. Add <link rel='stylesheet' href='css/earth3d.css'> inside head.
5. Before </body> add:
<script src='js/stars-engine.js'></script>
<script src='js/mouse-controls.js'></script>
<script src='js/earth-engine.js'></script>

No overwrite required.
