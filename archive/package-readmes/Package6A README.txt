
PACKAGE 6A INTEGRATION

1. Copy earth.css into css folder.
2. Copy earth.js and galaxy.js into js folder.
3. Copy universe.html contents near top of <body>.
4. Add in <head>:
<link rel="stylesheet" href="css/earth.css">

5. Remove old:
<script src="js/three-world.js"></script>

6. Add before </body>:
<script src="js/galaxy.js"></script>
<script src="js/earth.js"></script>

No overwrite except replacing old three-world.js usage.
