PACKAGE 4B INTEGRATION

1. Copy css/universe.css into your css folder.

2. Copy js/three-world.js into js folder.

3. Add inside body near top:
<div id="three-container"></div>

4. Add before </body>

<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<script src="js/three-world.js"></script>

5. Add in <head>
<link rel="stylesheet" href="css/universe.css">

This adds stars and rotating Earth wireframe background.
