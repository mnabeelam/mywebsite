
PACKAGE 4D INTEGRATION

1. Copy css/assistant.css into css folder.
2. Copy js/assistant.js into js folder.
3. Copy contents of widget.html before </body> in index.html.
4. Add in <head>:
<link rel="stylesheet" href="css/assistant.css">

5. Add before </body>:
<script src="js/assistant.js"></script>

No existing files need overwrite.
